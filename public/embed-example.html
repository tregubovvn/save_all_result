Пример 1: Встраивание через iframe

Простое встраивание с выбором полей через URL параметры:

<iframe src="index.html?mode=embed&fields=studentId,grade"></iframe>

Доступные поля: studentId, activity, grade, comment

Пример 2: Программное управление

Установка значений через JavaScript API:

const iframe = document.getElementById('myIframe');
const tracker = iframe.contentWindow.StudentTracker;

// Установить ИД студента
tracker.setFieldValue('studentId', 'STU12345');

// Установить оценку
tracker.setGrade('5');

// Получить значение
const grade = tracker.getFieldValue('grade');

// Сбросить форму
tracker.resetForm();

Пример 3: Обработка событий

Получение уведомлений при сохранении записи:

// Через CustomEvent
document.addEventListener('studentRecordSaved', (e) => {
  console.log('Запись сохранена:', e.detail.record);
});

// Через postMessage (для iframe)
window.addEventListener('message', (e) => {
  if (e.data.type === 'studentRecordSaved') {
    console.log('Запись:', e.data.record);
  }
});

Пример 4: Значения по умолчанию

Установка начальных значений через URL:

<iframe src="index.html?
  mode=embed&
  fields=studentId,activity,grade&
  studentId=STU001&
  activity=Лабораторная%20работа&
  grade=5
"></iframe>

Пример 5: Callback функции

Настройка через setConfig:

const iframe = document.getElementById('myIframe');
const tracker = iframe.contentWindow.StudentTracker;

tracker.setConfig({
  fields: ['studentId', 'grade'],
  mode: 'embed',
  serverUrl: '/api/submit',
  onSuccess: (record) => {
    console.log('Успех!', record);
  },
  onError: (error) => {
    console.error('Ошибка:', error);
  }
});
