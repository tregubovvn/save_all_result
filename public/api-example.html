📚 Пример использования Student API

Эта страница демонстрирует как использовать Student API для сохранения оценок студентов из любой HTML страницы.

1. Простое сохранение записи

2. Получить записи студента

3. Код для интеграции

Добавьте этот код в вашу HTML страницу:

<!-- Подключение API -->
<script src="https://tregubovvn.github.io/save_all_result/public/api.js"></script>

<script>
// Сохранить запись
StudentAPI.save({
  studentId: 'STU001',
  activity: 'Лабораторная работа',
  grade: '5',
  comment: 'Отличная работа'
}).then(result => {
  if (result.success) {
    console.log('Сохранено!', result.record);
  } else {
    console.error('Ошибка:', result.message);
  }
});

// Получить записи студента
StudentAPI.getRecords('STU001').then(records => {
  console.log('Записи:', records);
});

// Удалить запись
StudentAPI.deleteRecord(123).then(result => {
  console.log(result.success ? 'Удалено' : 'Ошибка');
});

// Получить ссылку на страницу студента
const url = StudentAPI.getStudentPageUrl('STU001');
console.log('Страница студента:', url);
</script>

4. Методы API

StudentAPI.save(data)
Сохранить новую запись
Параметры: { studentId, activity, grade, comment }
Возвращает: Promise<{success, message, record?}>

StudentAPI.getRecords(studentId)
Получить все записи студента
Параметры: studentId (string)
Возвращает: Promise<Array>

StudentAPI.deleteRecord(id)
Удалить запись по ID
Параметры: id (number)
Возвращает: Promise<{success, message}>

StudentAPI.getStudentPageUrl(studentId)
Получить URL страницы результатов студента
Параметры: studentId (string)
Возвращает: string (URL)
